**PSAWSProfile:** AWS SSO profile management for PowerShell

PSAWSProfile is a lightweight PowerShell module that makes AWS SSO-backed CLI profiles easier to work with day to day. If you manage many AWS accounts and roles through IAM Identity Center, you probably switch profiles constantly and often don't know whether your SSO session is still valid until a command fails.

The module addresses that in three ways:

* ***Discovery:*** It reads the shared AWS config file and builds an in-memory model of your SSO sessions and profiles. You can see what's configured and which profiles belong to which session.
* ***Session awareness:*** It inspects the local SSO token cache, so you can tell which sessions are active and which have expired.
* ***Safe profile switching:*** It sets the active AWS_PROFILE only after it confirms the profile's SSO session is live, so you find out about an expired session before you run a command.

**It's built the PowerShell way:** advanced functions that are pipeline-friendly and return objects. You filter, format and export the results however you like. It needs no extra tooling beyond the AWS CLI configuration you already have.

**Who it's for:** cloud engineers, admins and DevOps practitioners who work across multiple AWS accounts from the PowerShell prompt.

**In this session:** I'll walk through the design, demo the core commands, and show how the module is packaged, tested and released.
