Jorge Suarez is an Endpoint Platform Engineer and PowerShell enthusiast. He builds creative PowerShell solutions, including terminal user interfaces and Intune automation projects.

He writes about Microsoft Intune, endpoint management, Entra, Microsoft Graph, and automation. He shares code on GitHub and advocates for learning in public.

Jorge was a guest on [The PowerShell Podcast, episode 207](https://www.powershell.org/podcast/2025-12-29-the-powershell-podcast-building-powershell-tools-you-wish-existed-with-jorge-suarez/).
