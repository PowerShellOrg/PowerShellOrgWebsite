Pacific PowerShell User Group
By now, you've heard of coding agents, but maybe you think they aren't very good at PowerShell, or they don't write PowerShell the way you want. This session aims to change your mind. With the right setup, a coding agent can take on a script task and hand back code that follows a style guide and passes its tests. You don't need experience with coding agents.

We'll show that setup in an existing PowerShell repo. First, we add Frank's coding agent accelerator (copilot-repo-template) to it. The template is split into modules, so we choose which ones to keep.

Along the way, we explain Frank's PowerShell style guide, PSScriptAnalyzer for linting, and Pester for testing. Then we hand a coding agent a task in that repo and review what it changed. The template is public on GitHub, so you can add the same setup to your own projects afterward.
